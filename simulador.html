No se pudo cargar http://localhost:8081. Levantá el servidor con npx expo start en la carpeta del proyecto y recargá esta página.

Cómo recorrerla

  1. Empezá en Bienvenida y entrá con las credenciales de arriba.
  2. Inicio muestra el saldo en las dos monedas con la tasa en vivo del backend.
  3. Cambiar tiene la pieza firma: deslizá la pluma para confirmar.
  4. Actividad lista los movimientos con las dos monedas en cada fila.
Comprar, cambiar y enviar devuelven un error claro: la wallet de tesorería todavía no tiene fondos de testnet. El saldo del usuario nunca se mueve.
